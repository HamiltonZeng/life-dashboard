# v0.5 人生面板前端升级方案

方案起草于 2026-11-25，2026-11-27 调整至 v0.5。基于 v0.3 的前端结构，待 v0.4 Harness 的动作、澄清和回执契约通过验收后实施。

**把“今天要做什么”和“刚才记上了吗”放到首页。** 现在六个页面都能打开，日常记录、任务和报告已有完整流程。最值得改的是做完一件事要点几次，以及看到的结果能不能信。

## 打开后应该是什么样

以下是示意数据。假设今天的目标是练日语 20 分钟，打开电脑会看到这样的主次关系。

| 位置 | 示意内容 | 点了以后 |
| --- | --- | --- |
| 左侧导航 | 今天、任务、记录、数值、成就；底部设置 | 保留现有页面地址和浏览器返回行为 |
| 首页最上方 | **今天** · 11 月 25 日　｜　输入「今天练了 20 分钟日语」　［提交］ | 完成后在输入框下显示「已记录 · 日语学习 20 分钟」和「查看记录」 |
| 中间上半屏 | **今日与置顶任务**　日语听力　15 / 20 分钟　［去记录］ | 打开已带入任务的记录入口。实际时长留给用户填写 |
| 右侧，手机上移到任务下方 | **近 7 天**　日语学习时长　折线、单位、最近一次记录 | 点某一天查看当天来源。缺记录显示空缺，真实的 0 显示在零线上 |
| 页面下部 | **最近记录**　今天 19:20　日语听力　20 分钟　［查看］ | 打开原记录和修订历史，可看到对任务与成就的影响 |

标准首页先放一句话输入，再放今日任务。个人简介、常规成就与钱包摘要降到次要位置。极简首页保留同一个输入框、当前请求结果和「返回标准首页」。点退出应一次完成，保留输入的字和原有固定顺序。手机首屏给「今天、任务、记录、回顾、更多」五个入口，回顾收纳数值、成就和报告，常用记录在一只手能点到的位置。现有直达地址继续可用。

## 页面优先顺序

| 顺序 | 用户现在遇到什么 | 具体改法 | 交付时检查 |
| --- | --- | --- | --- |
| 1 · 今日任务与最近记录 | 今日任务排在头像、资料和钱包后面。记录成功后的变化需要翻多个面板找 | 今日任务每行留标题、进度和一个主要操作。按时间排列最近记录，点开看原文、改动与影响 | 记录一条 20 分钟学习后，从回执一次点回原记录。离开返回后仍能找到它 |
| 2 · 首页与报告入口 | 标准首页内嵌报告，手机首屏空间有限 | 标准首页提供独立的报告入口，极简首页继续保留一句话输入、当前回执和返回按钮 | 窄屏不出现横向滚动，报告与首页均可直达 |
| 3 · 复盘与设置 | 趋势依据、成就与钱包分散，AI 设置的技术用词偏多 | 展开查看事实来源和修订，把模型参数、用量收进详情 | 无数据与零值可区分，报告引用可跳到来源 |

备份下载、极简首页退出和登录提示是 v0.3 的缺陷修复。v0.5 将它们作为回归项。[v0.3 缺陷清单](../../log/v0.3/现阶段Bug与处理清单_2026-11-27.md)

## 各页改什么

| 页面 | 默认看什么 | 下一步怎么做 |
| --- | --- | --- |
| 今天 | 一句话记录、今日任务、最近记录。侧栏展示最多两张固定趋势 | 任务首选「去记录」。仅允许手动完成的任务才显示「标记完成」。AI 未开时直接呈现手动记录入口 |
| 任务 | 按今天、即将到期、已完成组织。日、周、月的规则写在任务标题下方 | 固定、排序、规则、奖励收进「更多」。从任务进记录时带出模板，只让用户填实际完成量 |
| 记录 | 按日期分组，行内显示时间、事项、实际值和保存状态 | 草稿写「只存在这台设备」，收到服务器回执再写「已保存」。修改历史值时，展示改前 → 改后和影响，一次确认 |
| 数值 | 当前值、单位、期间和趋势线 | 缺数据处让线断开。零值、空值和估算有不同的文字说明。点图上的某天展开来源及记录数 |
| 成就与钱包 | 离下一个里程碑差多少，以及最近一次解锁日期 | 点里程碑查看依据。余额与发放、冲正流水分开看，历史记录修改后显示「待复核」 |
| 报告 | 最近一期和报告范围；日、周、月可切换 | 先展示正文与事实依据，生成和时间设置折叠。允许查看哪些记录贡献了结果，来源已变化时提示更新 |
| 个人资料与设置 | 资料、显示、AI 和数据四个入口 | AI 状态用「还没连接」「请选择允许读取的模块」「可以使用」表示。模型名、技术参数、用量放详情。保留 v0.3 已更正的登录提示 |

输入框的反馈分四种情况。发送中保留原文；缺信息只问一件事；需要确认的变更并排显示原值和新值；已保存才显示记录链接。网络中断显示「结果还没确认」并提供「查询这次结果」，沿用原请求标识。手机软键盘弹出时保持输入框和提交按钮可见。浅色和深色都支持按 Tab 操作，弹窗关闭后焦点回到原按钮。

## 视觉怎么落地

- **颜色**　沿用深浅主题。浅色背景用暖灰白 `#F7F7F2`，正文用深墨色 `#182B35`，主要按钮用青绿 `#23645F` 配白字。深色用 `#17242B` 底和 `#F2F4F2` 正文。模块自选色留作列表小色点，提醒同时有文字或图标。
- **字号与密度**　中文正文 15–16 px，分组标题 20–24 px，数字及单位对齐。每条任务用细分隔线；需要确认、待处理或有独立操作的对象才做成卡片。桌面主区与侧栏约 2∶1，手机单列，主要触控按钮约 44 px 高。
- **走势与反馈**　趋势主图始终说明时间范围、单位和记录来源。点数据点可查看原记录。手机允许点选替代悬停。保存、撤销、待确认都在操作位置给出文字。
- **代码范围**　保留当前 TypeScript、HTML 和 CSS，先改页面装配、首页和公共样式。现有记录、奖励和统计接口足以支持改版。公共样式沿用 `packages/ui/src/styles.ts` 与 `tokens.ts`。页面代码位于 `apps/web/src/`，首页用 `home-profile.ts`，导航用 `main.ts`，任务与记录用 `panels.ts`，AI 回执用 `planning-ui.ts`，报告用 `report-ui.ts`，备份校验用 `export.ts`。

## 从 GitHub 借鉴的做法

| 项目 | 借鉴什么 | 用在哪里 |
| --- | --- | --- |
| [Unslop · Damir Sokolovsky](https://github.com/heydamir/unslop) | 用真实页面找出主次不分、装饰过多和操作重复，再逐屏修订 | 首页只设一个主要输入，任务按行列出。极简模式和标准模式用同一份数据逐屏复核 |
| [Super Productivity](https://github.com/super-productivity/super-productivity) | 一天的任务集中看，任务和日程有直接关系 | 首页围绕「今天」排，日/周/月规则留给任务详情 |
| [Loop Habit Tracker](https://github.com/iSoron/uhabits) | 用时间序列看长期变化，手机也能阅读 | 学习时长、运动等数值保留单位和日期，点进来源。这里沿用人生面板已有的缺失、零值口径 |
| [Impeccable](https://github.com/pbakaus/impeccable) | 在已有界面上检查可读性、响应式、对比度和交互 | 最终用两种主题、两种宽度、键盘和减少动效逐项验收 |

以上为交互和评审参考，产品运行依赖沿用现有项目。

## 实施与验收

| 批次 | 范围 | 通过条件 |
| --- | --- | --- |
| 一 · 固定交互基线 | 接通 v0.4 的澄清、预览、回执和来源跳转，保留 v0.3 导出及极简退出 | 下载的实际文件可在空库恢复。极简可直进直出。四种 Harness 结果有清楚的动作 |
| 二 · 打磨每天打开的首页 | 重排今日任务与最近记录，重做任务、记录行和手机导航 | 360 像素宽能完成「记录 20 分钟 → 查看来源」。1440 像素首页能直接看到今天要做什么。已保存、待确认、无记录都有明确文字 |
| 三 · 整理复盘页面 | 统一数值、报告、成就和设置，补键盘焦点、软键盘及外观测试 | 无数据与 0 明确区分。报告能追到事实。深浅两种主题的关键正文达到 4.5∶1 对比度。日程和导出可用键盘操作 |

建议由一名熟悉现有代码的开发者按三批实施，每批单独验收。首批可先独立交付。整版完成以真实下载并恢复、两种屏幕检查，以及原有任务/记录/奖励回归都通过为准。
