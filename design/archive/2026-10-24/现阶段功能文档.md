# 人生面板：现阶段功能说明

日期：2026-10-24。版本：v0.3第二阶段及审查收口。此文档记录现有能力，不表示真实DeepSeek或手机实机已经验收。

## 面板与日常使用

| 位置 | 当前代码支持 |
| --- | --- |
| 首页 | 标准/极简模式、聊天需求输入、追问、方案/记录/报告结果与对象跳转；3D仅预留 |
| 任务 | 主线、每日、周常、月常；颜色/筛选/首页固定，验收规则、有效期、适用星期、未来调整 |
| 数值 | 原始记录驱动计算、7天/月/季度/年趋势、粒度与视图异常筛选、重点数据固定 |
| 成就 | 系列多门槛及累计不同日期、近期成就、复核；连续天数不能冒充累计算法 |
| 记录 | 高级手动录入、任务关联、修订/删除、来源追溯；AI自然语言录入和估算独立注解 |
| 资料 | 模块字段、静态/观测/派生类型、保存提醒、记录投影和绑定保护 |
| 设置/报告 | 云端授权、执行偏好/用量；日/周/月按需报告及独立日程、覆盖范围、下次运行 |

默认模块：学习与发展、饮食与锻炼、财富与收获、娱乐和交际；支持自定义模块。财富部分是个人记录/数值，并非专业财务账簿。

## AI工作流

1. 一句话提出目标，生成有关联的目标、任务、模板、指标和成就；不因制定计划就生成已完成事实。
2. 自然语言录入发生过的活动，必要时追问。事实来源、数值/单位/时间由服务端校验，写入后统一重算。
3. 纠正历史记录或更新资料，展示整组差异，校验当前版本/绑定，再执行或补偿撤销。
4. 日/周/月报告使用SQL事实快照，模型生成带来源的分析；空周期用确定性空报告，不编造表现。
5. 日程默认关闭，各类型独立配置；关闭后阻止未来自动调用，停机恢复最多补最新一期，关机期间不能准时生成。
6. AI报价走独立受限通道、模板版本锁价；普通聊天和用户表单不能任意改奖励或余额，失败明确采用系统回退。

所有模型配置仅在服务端。缺少真实密钥/启用/授权时AI入口如实不可用，高级手动路径可继续使用。生产没有固定stub假装AI回答。先预览偏好、操作键重放、事实/候选版本保护和错误草稿恢复已保留。

## 数据与计算边界

- 自述/实测与营养等估算分开；估算默认不决定任务完成、成就或发币。
- 数值与报告依赖原始事实/修订及SQL口径，不用模型猜合计，也不把图表长粒度均值当总量。
- 日统计可重建，报告和摘要有来源及修订，补录后旧报告可标过时。
- 长期文字上下文使用受限关键字/时间范围检索，未引入向量库；模型推断不能自动变成个人资料。
- 数据可导出/恢复；恢复后收费作业和自动日程暂停，不自动补发模型请求。
