## 已确定的设计

- 明确创建/安排/记录请求默认自动完成合法低风险新增并可追溯；用户可改为先预览。该选择更新旧版“每个候选均手动确认”的设想。
- 不猜真实记录的数字、日期精度、完成状态或单位；必要事实缺失只追问最关键内容。历史纠错/覆盖和启用收费日程一张差异卡确认。
- 新建窗口首屏一行需求框，原表单进入高级设置；用户需要知道的目标、节奏和结果用自然语言保留。
- 日/周/月报告各自开关与时间，默认关闭；SQL事实快照供AI分析，关机/断网恢复最多补最新一期，不自动大批补费。
- AI奖励报价是独立受限通道，普通动作不可设置奖励/余额/解锁；旧锁价和账本不改。
- 先DeepSeek及SQL/摘要/全文检索；不引入首版向量库。真实模型、3D/兑换、同步等按各版本边界实施。
