# v0.2 候选 0.2.0-rc.1

在原手动记录 MVP 上加入资料、首页、周期任务、趋势、成就系列和代币账本。本轮修复四个发布问题：

1. 登录、相关路由、回到前台和周期边界显式生成当期任务，再读取投影；失败可见并可重试。旧待确认请求先以原键取回回执，再创建当前请求。
2. 默认生成覆盖全部启用模板；显式模板列表的 50 项上限保持。服务端按用户串行事务保证幂等和奖励额度。
3. 观测草稿包含绑定指纹。映射、类型、单位改变返回 409；缺失前提返回 428；原成功操作仍优先返回原回执。输入保留，采用新映射需明确确认。
4. 首页先判断周期/模块/模板有效性，按固定顺序去重，再补今日每日任务，最后截取五项；旧终结固定项不占位置。

任务分页在 SQL 层筛选；任务视图、模板、奖励资格和系列里程碑改用批量查询，消除同一 PostgreSQL Client 上的并发查询。浏览器事件按功能拆分，验收统一至 Codex 独立合成环境。

协议版本 `v0.2-phase2/1.1`；兼容旧成功回执，旧未确认观测草稿必须重新确认绑定。备份格式不变，0001–0004 不改，不新增历史任务奖励。18080 主环境尚未升级。具体测试、性能、资源和未测范围见 `docs/v02-phase3/`。
