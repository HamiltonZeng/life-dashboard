# v0.3 现阶段 Bug 与处理清单

2026-11-27。优先处理已有复现证据且能用现有架构收口的缺陷。表中的修复进入本次 PR 候选。

| 优先级 | 缺陷 | 本次处理与验收 |
| --- | --- | --- |
| P0 | DeepSeek 已返回，但手动任务附带记录规则、按记录验收缺规则或阈值为零时，业务预检直接结束，没有纠错机会 | 补充规则示例，把业务预检放入现有调用环。仅这三种已知任务规则错误可用现有尝试额度修正。修正后的方案先预览确认。一再失败时提示具体原因，不创建部分任务 |
| P1 | 点导出收到服务端 v3 JSON，浏览器的版本检查只接受 v1 | 浏览器与服务端共用备份版本定义，真实下载和空库恢复作为验收。继续拒绝未知版本 |
| P1 | 极简首页多出报告，缺少直接退出入口 | 报告只装配到标准首页，极简入口保留直接返回按钮。检查标准模式报告仍可打开，页面刷新后可直接退出 |
| P1 | 后台刷新设置页时可能清空正在填写的 DeepSeek 密钥 | 纳入已在本机验证的同账号表单保留修复。离开设置或提交时清除未提交内容 |
| P2 | 登录提示仍引用 v0.1 私有配置目录 | 更新为 v0.3 路径，继续由本机配置提供口令 |

现有证据支持修复失败路径，但无法反推真实报错的具体违规字段。跨用途失败分类、缺信息时稳定追问、诊断字段和真实供应商效果评估安排在 [v0.4 Harness](../../design/v0.4/Harness开发规划.md)。首页重排及移动交互属于 [v0.5](../../design/v0.5/前端升级方案.md)。
