# v0.1 延期功能清单

v0.1 冻结为本机、单用户、手动五面板 MVP。延期表示移除发布入口/能力承诺，不删除源码、Schema、迁移或已有数据。后续候选为 v0.2+，具体优先级取决于实际试用反馈，不承诺固定上线日期。

| 产品入口/能力 | 保留位置与当前状态 | 重新启用前提 |
| --- | --- | --- |
| AI 模块蓝图生成、真实 DeepSeek | `packages/ai`、`apps/web/src/ai-views.ts`、蓝图 Schema、0002_ai.sql；development/mock 可回归，MVP 拒绝写 API | 真实模型小样本、后台任务/恢复、费用台账与预算、取消和未知扣费策略 |
| AI 日报/周报、助手与报告转任务 | 设计文档及记录面板旧视图源码保留；发布入口隐藏 | 确定性统计、证据引用、版本/过期状态、明确采纳与预算 |
| RAG/语义检索 | 设计保留，无向量服务 | 有实际语义需求和召回率评估；用户权限、来源版本和删除传播 |
| 多端同步、设备管理 | `change_log`、`user_sync_clock`、幂等回执保留；sync=false | 正式会话/设备、push/pull/ack、游标边界/重建、冲突 UI 与设备撤销 |
| PWA 离线和后台 outbox | 浏览器仅持久草稿及待确认操作，不是离线同步 | 应用外壳缓存、可恢复队列、配额/升级策略、真机断网与重连闭环 |
| 手机可信 HTTPS、外网/VPS | 360px 布局保留；当前 127.0.0.1 本机入口 | 稳定地址、可信证书、Secure Cookie、正式鉴权和访问边界、恢复演练 |
| 周期任务调度与完整周期成就配置 | 实例/模板/已有周期授予保留；daily/weekly 仍拒绝 | 实例唯一键、规则版本与当地周期、暂停/恢复、历史评估与 UI |
| 完整模板/规则编辑迁移 | 通用定义创建与依赖展示保留；破坏性修改不开放 | 字段 key/类型/单位迁移、旧记录兼容、依赖重算与审计 |
| 饮食营养与训练专业算法 | 当前通用随记；旧设计保留 | 专门结构化模型、单位与来源、人工可核对计算，不能用随意数字字段代替 |
| 财富账本与账户余额 | 当前文字收获/通用记录；professional_ledger=false | 精确金额、币种、账户、收支/转账分离、复式/原子约束与核对 |
| 营地主页、角色/经验/目标卡片 | 首页继续空白；主页提案保留 | 来源与周期稳定、用户选定组件、null 语义、旧空白验收显式切换 |
| 后台队列、自动备份、费用结算 | 设计与运行目录保留；当前人工导出/空库恢复 | 领取租约/恢复、退避、预算结算、异机备份/保留策略与告警 |
| 原生 App、桌面客户端 | 独立 API 与 PostgreSQL 结构保留 | 先完成正式会话/同步，再做平台授权、存储与分发验收 |

手动导出不含浏览器草稿/待确认包、会话和 AI 生成任务/批次审计。恢复保留事实、墓碑、修订、回执和成就历史；不能用“延期”清库或删历史。当前全量快照/逐行恢复适合小规模个人使用，性能优化按实际数据测量再做。
