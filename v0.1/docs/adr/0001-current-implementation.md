# ADR 0001：保留当前实现，先完成质量收口

日期：2026-10-19；状态：S0 集成决策，适用于当前本地开发基线。

## 现状与决定

产品设计 v0.2 和本地 Docker/版本隔离要求继续有效。原技术规划中的 React/Vite 尚未实际采用：当前 Web 是原生 TypeScript、HTML 字符串和 UI 函数，`build-web.mjs` 使用 TypeScript compiler API，`dev-server.mjs` 提供静态文件及代理。存在 Vite 配置不等于当前运行经过 Vite。

本轮保留该实现，不在 R1–R5 修复中迁移框架。前端负责人先按页面、表单、弹窗和 AI 流程拆分，并交付可入库重跑的真实浏览器测试；如后续迁 React/Vite，单独提交迁移方案、范围与行为回归。

API 使用 Fastify + Zod；数据库为 PostgreSQL 18，业务 CRUD/事务/锁与聚合来源查询主要使用参数化 SQL。Drizzle 当前只在有限连接/健康检查路径使用，不宣称已经形成完整 ORM 仓储。迁移继续使用编号 SQL 与校验和，不为扩大 Drizzle 使用范围重写已验收事务。

领域计算由 Decimal.js/Luxon 执行。当前列表先取快照后分页，写入后同步重算派生状态，适用于小规模本地开发；后续性能任务应先测量 1千/1万/10万条隔离合成记录，再决定 SQL 聚合、索引和派生缓存。

## 本阶段约束

- 契约仍为 0.2.0；本轮为修复和增量配置说明，没有改变请求载荷、已有字段类型或迁移。数据库迁移仍为 0001、0002。
- 新建 AI 任务以同一用户写锁完成幂等检查、滚动 24h 计数和任务预留；释放连接后再调用供应商。外部网络不进入数据库事务。
- 模型单次时限与本次生成/重试执行总时限分开，不用 Fastify requestTimeout 代替业务截止时间。后者不包括数据库排队、应用事务和 CPU 执行的抢占式保证。
- 默认 mock；真实模型、货币预算预留、供应商计费账、后台 worker 与崩溃租约恢复属于 S3，尚未交付。
- 本机入口、开发会话及空白首页保留。主页提案只作为后续 S4 输入，没有自动启用新主页。
- `.runtime/data` 是持久数据；不通过清理缓存删除。浏览器离线能力、设备和同步协议属于 S1/S2，已有 change_log 不等于已可同步。

## 集成与前端交接

本轮不新增 npm 依赖，沿用已有锁文件和镜像摘要。S0-B 的浏览器运行器由前端负责人提出具体依赖/版本与安装位置后统一纳入；不为满足脚本名而加入不能运行的 `test:e2e` 占位命令。
前端仍需将正式浏览器用例入库并给出单一执行命令，包括空白首页、关联录入、门槛、删除复核、AI 预览/应用/撤销、409 和手机宽度。只有后端/API 测试通过，不能称为 S0 全部通过。

## 核对资料

实现依据：[Node AbortController](https://nodejs.org/docs/latest-v24.x/api/globals.html#class-abortcontroller)、[PostgreSQL 行级锁](https://www.postgresql.org/docs/18/explicit-locking.html)。实际行为另由本仓库的注入传输测试和独立 PostgreSQL 测试验证。
