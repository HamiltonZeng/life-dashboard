# v0.1.0 发布说明

日期：2026-10-19。范围：**本机 Docker、单用户、手动五面板 MVP**。

## 本版行为

- 默认 `APP_PROFILE=mvp`。手动配置模块/模板/任务/数值/成就，记录创建、编辑与软删除，真实数据驱动任务、统计与成就；首页空白。
- AI 默认关闭并由服务端拦截；保留 development/mock 回归、旧 AI 定义及历史数据。报告、同步、PWA、手机可信入口和专业账本不发布。
- 请求前保存完整待确认包；丢回执、刷新、修改工作草稿仍确认原键/原载荷。确认旧结果后可显式修改同一记录。
- 存储失败明确未保存；2xx 回执损坏仍待确认。编辑基线固定，冲突需用户明确选择新基线；列表刷新失败不改判已确认写入。
- 浏览器下载数据导出，CLI 在空且迁移一致的库恢复；保留墓碑、修订、幂等回执和成就依据，不恢复会话。
- 修复真实浏览器发现的成就模块切换后按钮仍禁用问题；模板回执按其实际 `schema_version` 验证。

## 验收与证据

发布门禁：`sh scripts/release/verify-mvp.sh`。逐项 A01–A16 和本轮状态分别在 `.runtime/test-artifacts/stage3-final/acceptance.json`、`run.json`；不允许以 SKIP 放行。最终结果见项目根目录 `log/2026-10-19_第三阶段最终验收.md`。

固定环境：Node 24 开发镜像、PostgreSQL 18 镜像；浏览器为官方 Playwright 1.64.1 镜像，实测 Linux arm64、Chromium 156.0.8078.4。浏览器镜像内 Node v24.21.0，PostgreSQL 18.6。具体摘要与运行信息在 `compose*.yaml` 和 `environment.json`。

上一集成基线 `7552747`。本版验收源码基线 `c100033fba55f8f1646bdc167ca818a04d76ceae`；最终版本标签 `v0.1.0` 指向随后仅补记基线哈希的文档提交，可通过 `git rev-parse 'v0.1.0^{commit}'` 获取完整提交 ID。无远端推送、无公网部署。

## 限制

仅本机使用；本地口令会话不等于正式多设备身份体系。浏览器清理数据可能丢失未提交草稿；人工导出仅包含服务器数据。备份 SHA-256 是完整性校验，不是加密。没有自动异机备份。

360px 为真实 Chromium 视口模拟，没有手机实机/软键盘、离线或跨设备验收；没有声称 CI。当前验收实现与执行由同一 Codex 会话完成，使用独立测试环境，不宣称另一 agent 的独立审查。

延期内容与重新启用条件见 [DEFERRED_FEATURES](docs/DEFERRED_FEATURES.md)。通过当前冻结范围后，新增功能进入后续版本，不在 v0.1 临时扩展。
