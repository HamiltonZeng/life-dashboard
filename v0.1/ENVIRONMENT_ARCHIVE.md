# v0.1 环境归档说明

2026-10-19 按用户要求，将应用、依赖、缓存、私有配置和持久数据库移动到 `../v0.2/`，本目录保留使用说明、发布说明和 docs。根开发日志未删除。

原 Docker 项目 `life-dashboard-v0-1` 的容器已正常停止并保留，没有执行 down、删除容器或清库。数据库在停库前完成一致性备份，并在 v0.2 启动后比较数据数量与内容指纹。

归档材料位于 `../v0.2/.runtime/migration-v02/`：

- `v0.1-before-move.dump`：完整数据库逻辑备份，600 权限，含个人数据。
- 原 Compose 配置、无环境密钥的容器元数据、数据库前后指纹、源码/依赖哈希。
- 依赖与物理数据目录 inode 记录，证明是移动而非重新下载或创建另一套空数据。

**不要直接重新启动旧容器。** 它们保存的是旧绑定路径；应用和数据已经移出。回退应从未变更的 `v0.1.0` 标签恢复到单独工作目录，使用旧迁移初始化一个空库并从上述备份恢复，再按旧配置建立独立容器项目。私有配置在 v0.2 中继续保留，恢复时在本地安全复制，不提交 Git。

恢复流程必须保持 v0.2 原库完整，不能把同一物理目录同时交给两套 PostgreSQL，也不能把旧容器指向一个被自动创建的空目录后误认为旧数据丢失。

本目录文档中的原 `v0.1/apps` 等路径反映发布时结构；当前开发和运行入口以 `../v0.2/README.md` 为准。原版本源码、历史提交与标签没有改写。
